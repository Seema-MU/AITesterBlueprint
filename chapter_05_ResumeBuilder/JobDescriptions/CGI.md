Position: Senior QA Automation Engineer

Position ID:

Employment Type: Full Time

Education Qualification: Bachelor's degree in computer science, Information Technology, Engineering, or related discipline.

Position Description: We are looking for an experienced Senior QA Automation Engineer with expertise in Playwright and Cursor AI to build and maintain modern automation solutions supporting enterprise digital transformation initiatives. The candidate will be responsible for developing scalable automation frameworks, implementing AI assisted test automation, and ensuring high quality software delivery through continuous testing practices.

This role requires hands on technical expertise in automation engineering, strong collaboration with Agile teams, and the ability to leverage AI tools to improve engineering productivity and software quality.

Key Responsibilities

 Design, develop, and maintain automation frameworks using Playwright with TypeScript/JavaScript.
 Develop automated Functional, Regression, Smoke, Sanity, and End to End test suites.
 Utilize Cursor AI to accelerate script development, code generation, debugging, and automation maintenance.
 Develop reusable automation components, utilities, and libraries.
 Automate REST API validation using Playwright API capabilities.
 Integrate automation suites with CI/CD pipelines (Azure DevOps, GitHub Actions, Jenkins).
 Analyze automation execution results and perform root cause analysis for failures.
 Participate in Sprint Planning, Backlog Grooming, and Agile ceremonies.
 Collaborate with Developers, Business Analysts, and Product Owners to ensure quality throughout the SDLC.
 Perform code reviews and promote automation best practices.
 Contribute to framework enhancements and continuous process improvements.

Mandatory Skills

 5–8 years of experience in Software Testing and Automation.
 Minimum 3 years of hands on experience with Playwright.
 Strong programming skills in TypeScript and JavaScript.
 Experience using Cursor AI or AI assisted development tools (GitHub Copilot, Claude Code, Windsurf).
 Experience with REST API automation and validation.
 Experience integrating automation with CI/CD pipelines.
 Hands on experience with Git, Azure DevOps, or GitHub.
 Strong understanding of Agile/Scrum methodologies.
 Excellent analytical, debugging, and problem solving skills.
 Strong communication and stakeholder collaboration skills.
